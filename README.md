# Smart Scheduler ✨

A modern full-stack appointment booking system built using Node.js and MongoDB.

## 🚀 Features
- 📅 Book appointments by selecting date
- ⏰ Interactive time slot selection
- 💳 Multiple payment options (UPI, Card, Cash)
- 📋 View bookings dynamically for each date

## 🛠 Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express
- Database: MongoDB

## ⚙️ How to Run Locally
1. Clone the repository
2. Install dependencies:
   npm install
3. Start the server:
   node server.js
4. Open in browser:
   http://localhost:5000
